# SL.VTGTHRIFT
A Java Swing desktop application featuring stock management, multi-item checkout, transaction history, and printable sales receipts for garment retail.
SL.VTGTHRIFT Inventory & POS System is a Java Swing desktop application designed for garment retail management. It features real-time inventory tracking with low-stock alerts, a multi-item cart point-of-sale system, formatted receipt printing, and persistent CSV data storage for sales and stock records.

Key Features 

Inventory Dashboard: Categorized garment stock tracking, real-time inventory valuation, and automated low-stock warnings.

Multi-Item POS System: Dynamic shopping cart management with automatic stock validation and checkout. 

Receipt Printing: Formatted receipt generation using Java’s native Printable API.   

Sales Reporting & History: Persistent sales logging with transaction summary breakdowns.   Local Data Persistence: Automated CSV file read/write operations for stock and transaction history.
